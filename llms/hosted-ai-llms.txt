# Hosted·ai

> Hosted·ai is a San Jose, California software company (founded 2024) providing a turnkey neocloud / GPU-as-a-Service (GPUaaS) platform that lets service providers, telcos and hosts turn NVIDIA GPU fleets into high-margin, multi-tenant AI cloud infrastructure. It offers software-defined GPU orchestration (multi-tenant pooling, adaptive scheduling, GPU overcommit), monetization and neocloud operations (billing, metering, white-label self-service panels), a GPU Mesh wholesale capacity network, and a full REST API (Admin Panel + User Panel).

## API

- [Hosted·ai Platform API docs](https://docs.hosted.ai/): Admin Panel + User Panel REST API. Bearer API-token auth; base URL per white-label deployment at https://USER_PANEL_URL/api. Current version 2.4.1.
- [GPUaaS Infrastructure API reference](https://docs.hosted.ai/admin-panel/gpuaas/gpuaas-infrastructure-api): GPU pools, nodes, GPU/NPU discovery, high availability, floating IPs, regions.
- [Manage API Tokens](https://docs.hosted.ai/user-panel/account-settings-22t5_c/security/manage-api-tokens): create bearer tokens with expiry and optional IP allowlist.
- [API FAQs](https://docs.hosted.ai/user-panel/faqs/api-faqs): base URL, auth header, HTTP methods, status codes, date handling.
